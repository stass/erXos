# What ERTS's objects may import from outside themselves. Read by
# make check-runtime-seam and the native build; the rule is in
# docs/design-runtime.md, "What ERTS imports". Names are separated by white space;
# a section is a group that can be dropped whole.
#
# The sections up to [musl] are the list the design keeps. Every [stock_*]
# section is the stock Unix layer sys/erxos was copied from. Its comment says what
# empties it, and that change deletes the section. The check reports a listed name
# that nothing imports.

# The BeamAsm flavour's objects alone (RuntimeSeam::JIT_ONLY): the interpreter and the
# hosted build leave this section out. BeamAsm's code space is JIT objects, each mapped
# twice (sys/erxos/erx_jit_memory.c; docs/design-runtime.md, "BeamAsm"), whose
# handles it closes once both mappings hold them. sysconf is asmjit's CPU detection.
# __clear_cache is asmjit's cache maintenance fallback. The rest are BeamAsm's assembly
# logs and perf outputs, which stay off, and the C++ runtime's registration of static
# destructors.
[beamasm]

__clear_cache
fopen fputs snprintf vsnprintf
