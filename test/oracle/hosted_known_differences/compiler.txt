# The known differences of `tools/erx oracle hosted` and
# `tools/erx oracle qemu` for OTP's compiler suites: cases whose result
# on erXos's hosted runtime or in a QEMU guest differs from stock OTP
# 29.1.2's, each for a reason erXos's design states, a cause it
# cannot run in Phase 1, or a bug that TODO.md names. Any other
# difference fails the comparison, and so does a row that then accounts
# for no difference, or whose cases show another status on erXos.
#
# One row per cause: suite, group path (outermost first, `/` between
# groups), `-` outside every group or `*` for every path, the case or `*`
# for every case, the Common Test status erXos shows (passed, failed,
# user_skip or auto_skip) and the reason, which is the rest of the line.
# Names are plain atoms; `*` is the only pattern. Of the rows covering a
# case, one naming the case wins over one naming only its group path. A
# `*` row claims only the cases that differ from stock; an exact row
# whose case agrees with stock is stale.
#
# suite        group  case                status     reason

# erXos runs no distribution in Phase 1 (design.md), and these compile the
# compiler on a shielded peer node, which needs it.
compilation_SUITE  -  self_compile             failed  cannot run: no distribution; the case starts a peer node (test_server:run_on_shielded_node)
compilation_SUITE  -  self_compile_old_inliner failed  cannot run: no distribution; the case starts a peer node (test_server:run_on_shielded_node)

# The release ships no port programs in Phase 1, and the case removes its
# work directory with os:cmd("rm -rf ...").
compile_SUITE      -  forms_2                  failed  cannot run: spawn port; os:cmd fails with open_port badarg

# The release ships beams without their sources (release_files.rb), and
# the case compiles lib/compiler/src/compile.erl.
compile_SUITE      -  makedep                  failed  cannot run: the release ships no sources

# The case compiles every module of the test directory, which holds the
# selected suites, and beam_types_SUITE.erl includes
# compiler/src/beam_types.hrl: a run that leaves beam_types_SUITE out
# passes the case on both sides and reports this row stale.
compile_SUITE      -  warnings                 failed  cannot run: the release ships no sources

# The release ships each application's beams and .app file, not its
# .appup (tools/lib/erx/release_files.rb), which the case reads. erXos
# updates replace a whole slot and reboot (docs/design-storage.md, System
# updates); no release_handler upgrade reads an .appup.
compile_SUITE      -  appup_test               failed  the release ships no .appup files: updates replace a whole slot (design-storage.md)

# crypto and public_key are outside the shipped set until the network
# service (design-runtime.md, "crypto, ssl, ssh, inets and the rest").
compile_SUITE      -  encrypted_abstr          failed  cannot run: C helper; debug_info_key needs crypto, which erXos does not ship (design-runtime.md)
compile_SUITE      -  deterministic_docs       failed  cannot run: compiles ssh.erl, which includes public_key.hrl; public_key is not shipped (design-runtime.md)

# statistics(runtime) fails with notsup where the backend reports a
# group's CPU time unsupported (design-runtime.md, edit 33); smith times
# itself with it.
inline_SUITE       p  smith                    failed  statistics(runtime) raises notsup where CPU time is unsupported (design-runtime.md, edit 33)
