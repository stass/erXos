# The verdict on every test of musl's libc-test that does not pass on erXos
# (tools/lib/erx/libc_test.rb, docs/design-stopgap.md "musl's own tests").
# One test per line:
#
#   NAME STATE KIND [at=PLACES] REASON
#
# STATE is the result the test must have: failed, timed_out or not_run. A
# test not listed must pass. A failed line pins at= PLACES, the FILE:LINE of
# libc-test's source that each of the test's error lines names, sorted and
# comma-separated. tools/erx check-libc-test fails on any result that
# differs from its line: a test that starts to pass, ends another way, or
# reports a failure at a place its line does not list needs its line
# changed or removed. A failed test that reports a new failure at a place
# already listed is not caught. A timed_out line is held to the timeout and
# a not_run line to its cause.
#
# KIND says why:
#   bug         a bug in erXos's code, with its TODO.md item in REASON
#   stopgap     a documented difference of the Phase 1 stopgap, which
#               erXos's kernel removes; REASON names where it is documented
#   upstream    musl's or libc-test's own code; REASON cites the source
#               that behaves so
#   cannot-run  Phase 1's musl refuses what the test's own object calls with
#               ENOSYS, so the run's plan does not start it; REASON is the
#               plan's cause, which the check holds the result to
#
# Each REASON below was checked against the test's source and output, and
# against musl v1.2.6 and its upstream master on git.musl-libc.org.
