# The rules of the line escape, which renders text attributed to a source
# (log records, names, inspector output) on one visible line. A program's own
# output is not such text and does not pass through it. Tab and newline are
# controls (Cc), so the line escape renders them like any other.
# The field escape, which /proc writes its files through, is injective: it
# writes tab, newline and backslash as \t, \n and \\, and each byte of a
# character the line escape renders, or of invalid UTF-8, as its field token.
