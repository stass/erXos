# us: the United States layout (docs/design-display.md, "Input events"), every key and
# button code of abi/formats/evdev.txt. The characters are those of 9front's US map in
# sys/src/cmd/aux/kbdfs/kbdfs.c (9front, commit eb49f1f8788c, SHA-256
# 4caa22dd9d599ef859584eac37bf7b107f9281c597fd4ddc581a21cd29dee255, MIT under
# lib/legal/NOTICE), whose scan codes 1 to 88 are evdev's: the none and shift layers
# (lines 162-200), and the ctl layer (lines 282-300), which gives a key that types a
# character the low five bits of its none layer's, and Space and the grave accent
# nothing. The US layout has no AltGr, so a key's altgr layers repeat none and shift. A
# key that types no character types its special rune at every layer, where kbdfs.c's
# ctl layer gives F1 to F12, Num Lock and Scroll Lock control characters; the keypad
# types its digits whatever Num Lock's state, as 9front's none layer does, where kbdfs
# turns the keypad into arrows with Num Lock off. As the design's layout gives them,
# Caps Lock is the caps lock, where 9front makes it Control; the right Alt is Alt, where
# 9front makes it AltGr; the right Meta key types Kmod4 like the left, and Pause types
# Kbreak, where kbdfs maps neither.
