# bondcheck: the bond check's test service (docs/design-bluetooth.md, "On QEMU against
# Bumble", "The bond check"). Its three characteristics are constants read at the three
# levels above open, each value its own level's name in ASCII, with no write, no
# subscription and no handler: a declared value is served whether or not a handler runs.
# A link with no key reads none of them; a Just Works bond's key reads encrypted alone; a
# Passkey Entry bond's key reads all three, bonded once the store has kept the bond.
