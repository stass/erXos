# evdev's codes, the one home of every evdev value erXos reads (docs/design-display.md,
# "Input events"): the event types, the end of one update and the report of dropped
# events, the key states, the codes of the keys of a USB keyboard and of the pointer's
# buttons, and the relative and absolute axes a mouse and a tablet report. A code erXos
# has no use for is not entered.
#
# Each entry is the name FreeBSD gives it, lowercased and prefixed with evdev_, so KEY_A
# is evdev_key_a, and its value is FreeBSD's. The source is sys/dev/evdev/
# input-event-codes.h at release/15.1.0, and for the key states enum evdev_key_events in
# sys/dev/evdev/evdev_private.h at the same release, both under the BSD-2-Clause license.
# FreeBSD's names put the key states and KEY_MAX under the KEY_ prefix of
# the key codes, so the prefix alone does not tell a key code from them: the enum evdev
# below does, as the one set of key and button codes.

# The event types (input-event-codes.h, lines 43-46).
limit evdev_ev_syn u16 0x00
limit evdev_ev_key u16 0x01
limit evdev_ev_rel u16 0x02
limit evdev_ev_abs u16 0x03

# The codes of EV_SYN: the end of one update, and the device's report that it dropped
# events since its last update (lines 58 and 61).
limit evdev_syn_report u16 0
limit evdev_syn_dropped u16 3

# The value of an EV_KEY event: released, pressed and the device's own repeat
# (evdev_private.h, lines 64-69, numbered from 0 in their order). The value is the
# event's signed field.
limit evdev_key_event_up i32 0
limit evdev_key_event_down i32 1
limit evdev_key_event_repeat i32 2

# The codes of the keys and buttons erXos reads, the closed set a row of a keyboard

# other keys of the USB keyboard map (abi/formats/hid.txt), each at its #define and
# KEY_DASHBOARD as the alias of KEY_ALL_APPLICATIONS (lines 271-272), the pointer's
# buttons (lines 341-343) and a touch (line 397). The key states and KEY_MAX
