# The inspection schema (docs/design-abi.md, "Inspection schema"): units,
# value types, stopgap reporters, trace rows, kinds with their attributes
# in field order, and paths. Its members but the trace rows, whose names
# are a namespace apart, have one namespace of their own; a root limit,
# scalar, enum or flags is named by @name. An attribute marked
# derived is one the inspector computes from the inputs it lists. A kind
# that erx_object_info reports has a root layout erx_info_<kind>, whose
# fields and reported bits are named after the kind's kernel attributes.
# A path marked present is a presentation type (docs/design-display.md,
# "Presentations"), whose names are a namespace apart as well.
# tools/gen_abi.rb generates erx_schema, erx_present and the host tool's
# table from it.
