# erx_object_info's topics and the report each writes (docs/design-abi.md,
# "Inspection schema"; docs/design-kernel.md, "Failure handling, diagnostics
# and debuggability"). A topic the inspector shows is named after the schema
# kind it reports, and its layout erx_info_<kind> has a field for each of
# that kind's kernel attributes the kernel can report, named after it, and a
# reported field with one bit per such field, named after it. A set bit says
# the field holds the attribute with its full meaning; a clear bit says the
# value means nothing. So a field that holds an enum is a plain integer
# here, its enum named in a comment: a reader never refuses a report over a
# value its clear bit disowns. tools/lib/erx/abi_inspection.rb checks the
# names against abi/inspection.txt.
enum info_kind u32
  value basic 0
  value machine 1
  value cpu 2
  value group 3
  value budget 4
  value thread 5
  value image_entry 6
